What you share

See exactly what is sent

Sent when "Share anonymous usage" is on:

  • Product name, category and brand of each Dirory item in your file
  • Quantity placed (models) and painted area in m² (materials)
  • Totals for the file, and SketchUp's own id for the file
  • A random install id, the plugin and SketchUp versions, and Windows or macOS
  • Search terms that returned no results at all

Never sent:

  • Model geometry, meshes, or the contents of your .skp file
  • File names, folder names or paths on your computer
  • Screenshots, thumbnails, or your undo history
